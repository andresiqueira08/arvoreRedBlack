# 🌳 Árvore Rubro-Negra (Red-Black Tree)

Implementação em **Java** de uma **Árvore Rubro-Negra (Red-Black Tree)**, com suporte às operações de **inserção** e **remoção de nós**, além de **busca** e **percursos**.  
O projeto tem como objetivo o estudo e a compreensão do balanceamento automático em árvores binárias.

---

## 🚀 Funcionalidades

- ✅ Inserção de nós mantendo as propriedades da árvore rubro-negra  
- ✅ Remoção de nós com rebalanceamento automático  
- ✅ Busca de valores na árvore  
- ✅ Percurso em ordem, pré-ordem e pós-ordem  
- ✅ Impressão estruturada da árvore no console  

---

## 🧠 Conceitos Envolvidos

A Árvore Rubro-Negra é uma estrutura de dados **auto-balanceada** derivada da árvore binária de busca.  
Ela garante uma **complexidade O(log n)** para inserção, remoção e busca.  
As propriedades principais são:

1. Cada nó é **vermelho** ou **preto**  
2. A raiz é sempre **preta**  
3. Nós vermelhos não podem ter filhos vermelhos  
4. Todo caminho da raiz até uma folha nula tem o mesmo número de nós pretos
